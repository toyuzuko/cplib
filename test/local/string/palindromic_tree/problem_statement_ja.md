# Problem Statement

文字列 `S` が与えられます。`S` の distinct な回文部分文字列を調べます。

回文とは、左から読んでも右から読んでも同じになる文字列です。部分文字列が distinct であるとは、その文字列が他の回文部分文字列と文字列として一致しないことを意味します。

この問題では、distinct な回文部分文字列の個数、`S` の最長の回文接尾辞、そして各 distinct 回文部分文字列とその出現回数を出力してください。

## Input Format

```text
S
```

`S` は空文字列でも構いません。

## Output Format

以下を出力してください。

1. `S` の distinct な回文部分文字列の個数
2. `S` の最長の回文接尾辞
3. distinct な回文部分文字列を、長さが短い順、同じ長さなら辞書順で並べた各行

3 つ目以降の各行には、回文文字列とその出現回数を 1 つの空白で区切って出力してください。

## Constraints

以下の記号は `config.py` で設定します。同梱の `test_runner.py` は
`NUM_CASES = 100`、`TIMEOUT_SECONDS = 2.0` で実行されます。これらの設定は
`naive.py` が通常 2 秒程度で終わるように選んであります。

- `0 <= |S| <= LENGTH_MAX`
- `S` の各文字は `ALPHABET` に属する

## Notes

同梱の `naive.py` はすべての部分文字列を調べ、各部分文字列が回文かを直接判定
するため、最悪計算量は `O(|S|^3)` です。設定ファイルの記号で書けば
`O(LENGTH_MAX^3)` です。
