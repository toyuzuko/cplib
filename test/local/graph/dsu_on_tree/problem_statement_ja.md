# Problem Statement

根を頂点 `0` とする根付き木が与えられます。各頂点には色が 1 つずつ
付いています。各頂点について、その部分木に現れる異なる色の個数を
出力してください。ここで部分木とは、その頂点自身とその子孫全体を
指します。

## Input Format

```text
n
p_1 p_2 ... p_(n-1)
c_0 c_1 ... c_(n-1)
```

`n = 1` のときは親を与える行は省略されます。木は頂点 `0` を根とし、
`p_i` は `1 <= i < n` に対する頂点 `i` の親です。

## Output Format

`n` 個の整数を空白区切りで出力してください。`i` 番目の整数は、頂点
`i` の部分木に現れる異なる色の個数です。

## Constraints

以下の記号は `config.py` で設定します。同梱の `test_runner.py` は
`NUM_CASES = 100`、`TIMEOUT_SECONDS = 2.0` で実行されます。これらの設定は
`naive.py` が通常 2 秒程度で終わるように選んであります。

- `1 <= N <= N_MAX`
- `1 <= i < N` に対して `0 <= P_i < i`
- `0 <= i < N` に対して `0 <= C_i <= COLOR_MAX`

## Notes

同梱の `naive.py` は各頂点ごとに部分木を独立に走査するため、最悪計算量は
`O(N^2)` です。設定ファイルの記号で書けば `O(N_MAX^2)` になります。
