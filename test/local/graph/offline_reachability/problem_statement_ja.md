# Problem Statement

有向グラフと到達可能性クエリが与えられます。各クエリについて、始点から
終点へ到達できるかを判定してください。

# Input Format

入力は次の形式で与えられます。

```text
N M Q
u_0 v_0
u_1 v_1
...
u_{M-1} v_{M-1}
s_0 t_0
s_1 t_1
...
s_{Q-1} t_{Q-1}
```

各辺は `u_i` から `v_i` への有向辺です。各クエリでは、`s_i` から
`t_i` へ到達できるかを出力します。頂点は自分自身へ到達可能とします。

# Output Format

`Q` 行出力してください。`i` 行目には、`t_i` が `s_i` から到達可能なら
`1`、そうでなければ `0` を出力してください。

# Constraints

- `1 <= N <= N_MAX`
- `0 <= M <= M_MAX`
- `1 <= Q <= Q_MAX`
- `0 <= u_i, v_i < N`
- `0 <= s_i, t_i < N`

参照実装 `naive.py` は各クエリに BFS で答え、計算量は
`O(Q_MAX * (N_MAX + M_MAX))` です。
